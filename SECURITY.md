# Política de segurança

Este repositório é um exemplo didático. Ele não implementa autenticação e não deve receber dados reais nem ser usado para processar transações financeiras.

## Reportar uma vulnerabilidade

Não publique em uma issue aberta detalhes que permitam explorar uma vulnerabilidade. Use o recurso de relato privado de vulnerabilidades do GitHub se estiver habilitado para este repositório.

Se o recurso não estiver disponível, abra uma issue pedindo um canal privado de contato, sem incluir código de exploração, credenciais ou dados sensíveis. Os detalhes técnicos podem ser enviados depois que os mantenedores indicarem um canal privado.

Os relatos devem incluir, quando possível, os passos para reproduzir o problema, o impacto observado e a versão ou commit afetado. Não envie dados de produção ou informações pessoais.
